# android-joystick
Moonlight was too slow for me for game streaming, so I wanted to switch to Parsec. But Parsec doesn't let you use a custom controller layout, and I couldn't find any free tool that solved this nicely.So I just built it myself over a weekend.Here's how it works:On the PC — a small Node.js server runs in the background listening on port 5000. When it gets a request like `?key=a&action=down` it calls a compiled AutoHotkey script which simulates the actual keystroke on Windows. AHK handles the key down and key up separately so you can hold keys, which is what games need.On Android — MacroDroid floating buttons sit on top of the screen. Each button just fires an HTTP GET request to the PC. That's literally it. No Bluetooth, no special app, no pairing.Optionally you can pass a `time` parameter and the key auto-releases after that many milliseconds. Useful for a quick tap.The whole server is about 15 lines of Node. The AHK script is 2 lines.Will put it on GitHub soon. https://lnkd.in/gBj776TX #nodejs #autohotkey #pars
